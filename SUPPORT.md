# Getting help

openKWL is a hobby project with no paid support. Answers may take a while.

1. **Check the docs first:** the [FAQ and troubleshooting](docs/FAQ.md), the
   [user guide](docs/USER_GUIDE.md), and the [installation guide](docs/INSTALL.md), which
   includes *If something goes wrong*.
2. **Search the [issues](../../issues?q=is%3Aissue)**, including closed ones: someone may have
   had the same problem.
3. **Ask or report:**
   - questions and ideas: [Discussions](../../discussions), if enabled, or a
     [feature request](../../issues/new?template=feature_request.yml);
   - something doesn't work: a [bug report](../../issues/new?template=bug_report.yml);
   - you tried another unit model: a [unit report](../../issues/new?template=unit_report.yml);
   - a security problem: privately, as described in [SECURITY.md](SECURITY.md).

**Please don't contact Helios** about openKWL. It is not their product, and they can't help
with it.

**If your ventilation isn't working and you need it now:** go back to the original firmware
([INSTALL.md, step 6](docs/INSTALL.md#step-6-go-back-to-the-original-firmware)). It is designed
to work whatever state openKWL is in, because the stock bootloader runs before any firmware;
verified on one unit (a dry run with the original image).
